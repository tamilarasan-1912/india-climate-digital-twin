# Prithvi WxC rollout checkpoint

The official IBM/NASA checkpoint is approximately 28.4 GB and is intentionally
**not stored in this Git repository**.

Expected filename:

`prithvi.wxc.rollout.2300m.v1.pt`

Recommended local path:

`models/prithvi-wxc/prithvi.wxc.rollout.2300m.v1.pt`

Official model repository:

`ibm-nasa-geospatial/Prithvi-WxC-1.0-2300M-rollout`

The backend checks for the checkpoint but does not claim inference is available
until the checkpoint, PyTorch, TerraTorch, and validated MERRA-2 inputs are all
present.
